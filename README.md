# A little bouquet for Renae, aka Short Cake ♡

A personalized pink website with an animated gift box that reveals an original bouquet of tulips, daisies, and lilies. Includes falling petals, optional gentle chimes, a replay button, flower meaning cards, and a sweet letter.

Open index.html in a browser. No build step or API key is needed. Upload index.html, styles.css, and script.js to any static website host. Google Fonts is optional, with local font fallbacks.
